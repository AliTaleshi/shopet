# شاپت (Shopet)

فروشگاه اینترنتی لوازم حیوانات خانگی — Persian online shop for pet supplies.

- Backend: Spring Boot 4 (Java 21), PostgreSQL 16, Flyway, JWT
- Frontend: React + TypeScript + MUI (RTL)
- Runs with Docker Compose

See [docs/DESIGN.md](docs/DESIGN.md) for the full design. Setup instructions follow as the project is built.
